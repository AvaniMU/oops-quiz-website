# OOP Quiz Website

An interactive quiz website designed to help users test and improve their understanding of Object-Oriented Programming concepts through engaging questions and instant feedback.

## Features

- Interactive OOP questions
- Multiple-choice answers
- Instant feedback
- Score calculation
- Simple and user-friendly interface
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was created to provide a simple and interactive way for students to practice and strengthen their understanding of Object-Oriented Programming concepts.
